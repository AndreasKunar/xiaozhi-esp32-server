============================================================

Example Model  
Hiyori Momisaki - PRO

============================================================

This example model is created using Cubism 3.0 as a standard model asset.

It is suitable for learning about the construction of deformers and how to use parameters.
The model’s shoulders utilize the new feature called “Glue.”
